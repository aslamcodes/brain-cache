**What is AI?**
Machine jobs that performs jobs that mimic human behavior. 
- Problem solving
- decision-making
- NLP
- Speech Recognition
- Robotics

**What is ML**? 
Machines that gets better at a task without programming

**Deep Learning**?
Machines that have artificial neural network inspired by human brain

**GenAI**?
Subset of AI that Generates things, more of a marketing term. More often under Deep Learning. 
utilises advanced machine learning techniques, ie GPTs

> AI is more about using existing data to make decisions, whereas GenAI uses existing data to create new data.
