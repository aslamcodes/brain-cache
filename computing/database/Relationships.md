## One-to-One Relationship
- **A person has one passport**, and each passport belongs to one specific person.[](https://www.yourdictionary.com/articles/examples-one-to-one-relationships)
- Every student is assigned a unique student ID, and each ID matches only one student.[](https://help.claris.com/en/pro-help/content/one-to-one-relationships.html)
- Each person owns one car, and each car is owned by one person.[](https://www.yourdictionary.com/articles/examples-one-to-one-relationships)
## One-to-Many Relationship
- **One customer places many orders**, but each order is linked to a single customer.[](https://www.geeksforgeeks.org/dbms/one-to-many-relationship-example/)
- A company can have several phone numbers, but every phone number belongs to only one company.[](https://www.geeksforgeeks.org/dbms/one-to-many-relationship-example/)
- One car maker builds multiple models, but each model is made by only one car maker.[](https://www.geeksforgeeks.org/dbms/one-to-many-relationship-example/)
- One city is in one country, but a country has many cities.[](https://five.co/blog/how-to-create-one-to-many-relationships-in-sql/)
## Many-to-Many Relationship
- **Students and classes**: A student can register for many classes, and a single class can have many students enrolled.[](https://help.claris.com/en/pro-help/content/many-to-many-relationships.html)
- Customers and products: Each customer can buy several products, and every product can be purchased by various customers.[](https://byjus.com/gate/many-to-many-relationship-in-dbms-notes/)
- Users and roles: A user can have multiple roles, and each role can be assigned to multiple users in a system.[](https://stackoverflow.com/questions/51463706/can-somebody-give-a-practical-example-of-a-many-to-many-relationship)
